Accessibility Statement

Residences Extended Stay is committed to making this website more usable and accessible for a broad range of visitors, devices, and assistive technologies.

Our Approach

We aim to improve readability, keyboard access, link clarity, responsive behavior, and compatibility with modern browsers and assistive technologies as the site evolves.

Ongoing Improvements

Because the site is actively being expanded, some areas may still be in progress. We review navigation, forms, contrast, and interactive elements as new pages and features are introduced.

Need Assistance?

If you have difficulty using any part of this site or need information in an alternative format, please contact us through our contact page so we can help directly.
