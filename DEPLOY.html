Option A: Deploy on Netlify (Recommended) FREE

Netlify is the best option. It's free, handles HTTPS automatically, processes the Netlify Forms on every page, and works with custom domains. No technical setup required beyond drag-and-drop.

1Create a free Netlify account

Go to netlify.com and sign up with an email address or GitHub account.

2Deploy via Drag-and-Drop

From your Netlify dashboard, find the section that says "Want to deploy a new site without connecting to Git? Drag and drop your site output folder here."

Select the entire "Residences Extended Stay" folder from your computer and drag it into that zone. Netlify will deploy the site in about 30 seconds.

3Connect your custom domain

In your Netlify site dashboard, go to Domain settings → Add a domain. Add each domain you want to use:

  • residencesextendedstay.com (primary — point to this Netlify site)
  • residencesatsolomonpond.com (redirect to /marlborough.html)
  • residencesatinternationalplace.com (redirect to /tewksbury.html)
  • residencesatdanielwebster.com (redirect to /merrimack.html)

Netlify will walk you through adding DNS records at your domain registrar (GoDaddy, Namecheap, etc.). HTTPS is provisioned automatically — no SSL certificate to buy.

4Set up property-specific domain redirects

Create a file called _redirects in the root of your site folder with these rules:

https://www.residencesatsolomonpond.com/* https://www.residencesextendedstay.com/marlborough.html 301 https://residencesatsolomonpond.com/* https://www.residencesextendedstay.com/marlborough.html 301 https://www.residencesatinternationalplace.com/* https://www.residencesextendedstay.com/tewksbury.html 301 https://residencesatinternationalplace.com/* https://www.residencesextendedstay.com/tewksbury.html 301 https://www.residencesatdanielwebster.com/* https://www.residencesextendedstay.com/merrimack.html 301 https://residencesatdanielwebster.com/* https://www.residencesextendedstay.com/merrimack.html 301

This ensures each property's own domain routes visitors to the correct page on the main site.

5Verify forms are live

All inquiry forms use Netlify Forms (data-netlify="true"). Once deployed, go to your Netlify dashboard → Forms tab. You should see all form names listed (homepage-inquiry, marlborough-inquiry, tewksbury-inquiry, merrimack-inquiry, general-inquiry). Submit a test entry from each page to confirm they're working. Set up email notifications under Form notifications → Email so you receive every lead.

Option B: Deploy on Vercel FREE

Vercel also works well for static sites. The main difference: Vercel does not process HTML forms natively. If you use Vercel, you'll need to add a third-party form handler (Formspree, Basin, etc.) or replace the form action URLs.

1Push files to a GitHub repository
git init git add . git commit -m "Initial site deploy" git remote add origin https://github.com/YOUR_USERNAME/residences-extended-stay.git git push -u origin main
2Connect to Vercel

Go to vercel.com, sign in with GitHub, and import your repository. Vercel auto-detects the static site and deploys immediately.

3Add custom domain

In your Vercel project settings, go to Domains and add your domains. Vercel handles HTTPS automatically.

Before Going Live — Checklist

Assets to Create or Upload

  • assets/favicon-32x32.png — 32×32px favicon
  • assets/favicon-16x16.png — 16×16px favicon
  • assets/apple-touch-icon.png — 180×180px Apple touch icon
  • assets/residences-logo.png — Logo image (optional — text fallback already in nav)
  • site.webmanifest — PWA manifest (optional)
Quick favicon: Use a free tool like favicon.io to generate a favicon set from text ("R") or upload your logo. Drop the generated files into the assets/ folder.

Configure Google Analytics (Optional)

Add your GA4 tracking script before </head> in each HTML file, or use Netlify's snippet injection to add it site-wide from the dashboard without touching files.

Submit to Google Search Console

  1. Go to search.google.com/search-console
  2. Add your domain as a property
  3. Verify ownership (Netlify makes this easy with TXT records)
  4. Submit https://www.residencesextendedstay.com/sitemap.xml

Update Sitemap Dates

Update the <lastmod> dates in sitemap.xml to the actual go-live date before submitting to Google.

Ongoing Maintenance

  • To update rates: Edit the pricing tables in marlborough.html, tewksbury.html, and merrimack.html. Re-deploy by dragging the updated folder to Netlify, or push to GitHub if using Vercel.
  • To update content: Edit the HTML files directly. All styling is in styles.css. All JavaScript is in script.js.
  • To add a new page: Copy an existing page as a template, update the content, and add it to sitemap.xml.
  • Lead notifications: Configure in Netlify dashboard → Forms → Notifications → Add email notification.
Questions or changes? This site was built on a static HTML/CSS/JS stack — no framework, no database, no server-side code. Any web developer can maintain or extend it. All files are in the "Residences Extended Stay" folder on your computer.
